NVIDIA DLL AND SDK
The package contains no nvngx_dlss.dll, drivers or SDK headers. The mod only
uses production x64 DLSS SR libraries present in local NVIDIA components,
with valid Authenticode signatures. It compares versions and checks the
declared minimum driver. NGX determines final availability. There is no
library download, manual DLL picker or private DLSS fallback library.
The original NVIDIA cache is not modified. A single working copy is prepared
for NGX loading; it is not a source if the local NVIDIA library disappears.
Libraries are not searched for in other games or executed to verify identity.
